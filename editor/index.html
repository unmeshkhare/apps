How to publish your changes

  1. Press Download list. A file called apps.json is saved to Downloads.
  2. On GitHub open your apps repository → Add file → Upload files.
  3. Drag in apps.json (and any new app folders or icon images).
  4. Press Commit changes. The site updates in about a minute.
